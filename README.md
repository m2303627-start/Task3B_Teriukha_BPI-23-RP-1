# Справочник пользователей (REST API)

Небольшое интерактивное веб-приложение для загрузки и отображения данных
из публичного REST API `jsonplaceholder.typicode.com`.

## Запуск

1. Скачайте и распакуйте архив (или склонируйте папку проекта).
2. Откройте файл `index.html` в современном браузере
   (Chrome, Firefox, Edge, Safari).
3. Дополнительная сборка и установка зависимостей не требуется — используется
   только HTML, CSS и чистый JavaScript.

> Примечание: для корректной работы `fetch` к внешнему API может потребоваться
> доступ в интернет. Открытие через `file://` в большинстве браузеров работает,
> но при возникновении CORS-проблем запустите локальный сервер, например:
> `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Использование

- **Загрузить пользователей** — выполняет `GET /users`, показывает 10 карточек
  с именем, email и городом.
- **Поиск по имени** — фильтрует уже загруженный список без нового запроса,
  без учёта регистра. При отсутствии совпадений выводится
  «Пользователи не найдены».
- **Показать публикации** (на карточке пользователя) — выполняет
  `GET /posts?userId=ID` и выводит заголовки и тексты первых трёх публикаций
  в отдельной области.

## Обработка состояний и ошибок

- Во время запросов показывается «Загрузка...».
- Кнопка «Загрузить пользователей» блокируется на время запроса и снова
  включается в `finally`.
- Проверяется `response.ok`; HTTP- и сетевые ошибки перехватываются
  `try/catch/finally`. После ошибки можно повторить попытку.

## Результаты проверок

| Проверка | Результат |
|---|---|
| Нажатие «Загрузить пользователей» | ✅ Появляются 10 пользователей с именем, email и городом |
| Поиск «Leanne» | ✅ Остаётся только подходящая запись |
| Поиск неизвестного имени | ✅ Появляется сообщение «Пользователи не найдены» |
| Кнопка «Показать публикации» | ✅ Отображаются заголовки и тексты первых трёх публикаций |
| Подмена `/users` на `/userz` (HTTP 404) | ✅ Появляется сообщение об ошибке |
| Возврат правильного адреса | ✅ Повторный запрос работает |
| CSS-оформление | ✅ Отступы, цвета, читаемые карточки и кнопки |
| Обновление страницы без перезагрузки | ✅ Всё обновляется динамически через DOM |
