# Справочник пользователей (REST API)

Приложение на HTML, CSS и чистом JavaScript для загрузки и отображения
пользователей и их публикаций из публичного API `jsonplaceholder.typicode.com`.

## Запуск

1. Распакуйте архив с проектом.
2. Откройте `index.html` в браузере (Chrome, Firefox, Edge, Safari).
3. Сборка и установка зависимостей не требуются.

## Использование

- **Загрузить пользователей** — `GET /users`, выводятся 10 карточек
  (имя, email, город).
- **Поиск по имени** — фильтрация уже загруженного списка без нового запроса,
  без учёта регистра. При отсутствии совпадений — «Пользователи не найдены».
- **Показать публикации** — `GET /posts?userId=ID`, выводятся заголовки
  и тексты первых трёх публикаций в отдельной области.

Во время запросов показывается «Загрузка...», кнопка загрузки блокируется
и снова включается в `finally`. HTTP- и сетевые ошибки обрабатываются
через `response.ok` и `try/catch/finally`, повторная попытка доступна.
